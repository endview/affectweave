# Changelog

## v0.2-demo — 2026-08-03

Context Pipeline release.

### Features

- Added host-neutral `ContextPackage`.
- Split context selection from output rendering.
- Added text, JSON and generic message-block renderers.
- Added auditable context budget and trimming reports.
- Added Context trace metadata.
- Added CLI rendering formats and budget output.
- Preserved the v0.1 host lifecycle, compatibility accessors and legacy packet loading.
- Expanded the automated suite to 28 tests.

## v0.1-demo — 2026-08-02

Initial public demo.

### Features

- Persistent Persona, medium-term state, emotions and relationships.
- ActiveThread and evidence-backed episodic memory.
- Host-neutral `EnhancementPacket` compiler.
- Structured AI-output validation and bounded state proposals.
- L0/L1/L2/L3 behavior-result lifecycle.
- In-memory and SQLite repositories.
- Python integration API and CLI workflow.
- Example host and automated tests.
